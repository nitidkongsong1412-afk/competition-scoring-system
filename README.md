# ระบบบันทึกและประมวลผลคะแนนการประกวด "เท่อย่างเซียน"

ระบบเว็บแอปพลิเคชันสำหรับบันทึกและประมวลผลคะแนนการประกวดคลิปสร้างสรรค์ "เท่อย่างเซียน" ออกแบบให้ใช้งานง่าย สะดวกสำหรับกรรมการทุกวัย (ไม่ต้องใช้ PIN) รองรับการใช้งานผ่านคอมพิวเตอร์, iPad/แท็บเล็ต และสมาร์ทโฟน พร้อมระบบแอดมินคำนวณคะแนนเฉลี่ย จัดอันดับ และตัดเกรดเหรียญรางวัลอัตโนมัติ

---

## 🚀 วิธีการเปิดใช้งานระบบ (สำหรับ Windows)

1. **ดับเบิลคลิกที่ไฟล์ `start_system.bat`**
2. ระบบจะเริ่มทำงานและเปิดหน้าเว็บเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:3000`
3. ในหน้าต่างสีดำจะแสดง **IP สำหรับเปิดบน iPad / แท็บเล็ต** ในวง Wi-Fi เดียวกัน เช่น `http://192.168.1.X:3000`

---

## 🔑 ข้อมูลเข้าสู่ระบบผู้ดูแลระบบ (Admin)

- **URL เข้าสู่ระบบ**: `http://localhost:3000/admin`
- **รหัสผ่านเริ่มต้น**: `admin1234`
*(สามารถเปลี่ยนรหัสผ่านได้ในเมนู "ตั้งค่าระบบ & รหัสผ่าน" ภายในหน้าแอดมิน)*

## 🌟 ฟังก์ชันหลักของระบบ

### 1. หน้าหลักสำหรับกรรมการ (Homepage)
- การ์ดรายชื่อกรรมการทุกคน แยกตามระดับชั้น ม.1 ถึง ม.6 (ระดับละ 3 ท่าน)
- แสดงแถบสถานะการตรวจแบบเรียลไทม์ (ยังไม่เริ่ม / กำลังตรวจ / ตรวจเสร็จแล้ว)
- **1-Click เข้าสู่หน้าลงคะแนน**: กรรมการเพียงคลิกที่ชื่อของตนเอง เข้าสู่หน้าลงคะแนนได้ทันที ไม่ต้องกรอกรหัสผ่าน

### 2. หน้าลงคะแนน (Scoring Page)
- ตารางรายการห้องเรียนในระดับชั้นที่ได้รับมอบหมาย
- **5 เกณฑ์การตัดสินมาตรฐาน (รวม 100 คะแนนเต็ม)**:
  1. คลิปสร้างสรรค์สื่อถึงและแสดงออกถึงความเป็นไทย (เต็ม 40 คะแนน)
  2. ท่าทางถูกต้องตามโจทย์ที่กำหนดและสวยงาม มีความเป็นธรรมชาติ คล่องแคล่ว นุ่มนวล มีทักษะ มีความพร้อมเพรียง (เต็ม 30 คะแนน)
  3. ความตรงต่อเวลา / นักเรียนครบตามจำนวน (เต็ม 10 คะแนน)
  4. การถ่ายทำ ตัดต่อ บันทึกภาพ ชัดเจน (เต็ม 10 คะแนน)
  5. ไม่มีคำหยาบ ความรุนแรง บุคลิกภาพ การแต่งกายเป็นระเบียบเรียบร้อย (เต็ม 10 คะแนน)
- บังคับกรอกเฉพาะเลขจำนวนเต็ม ไม่เกินคะแนนเต็มแต่ละข้อ
- **Auto-save อัตโนมัติ**: บันทึกทันทีที่พิมพ์ พร้อมไฟสถานะสีเขียวเมื่อกรอกครบ
- ช่องความคิดเห็น/ข้อเสนอแนะเพิ่มเติมรายห้อง (ไม่บังคับ)
- ปุ่มยืนยันผลการลงคะแนนรายห้อง และระบบจุดพลุฉลองเมื่อตรวจครบ 100%

### 3. ระบบคำนวณผลและตารางอันดับรางวัล (Live Leaderboard)
- รวมคะแนนจากกรรมการทั้ง 3 ท่าน และคำนวณ **คะแนนเฉลี่ย (÷ 3)** อัตโนมัติ
- จัดอันดับ **ชนะเลิศอันดับ 1, รองชนะเลิศอันดับ 1, รองชนะเลิศอันดับ 2** แบบเรียลไทม์
- ตัดเกรดเหรียญรางวัลอัตโนมัติ:
  - 🥇 **เหรียญทอง**: 80.00 คะแนนขึ้นไป
  - 🥈 **เหรียญเงิน**: 70.00 - 79.99 คะแนน
  - 🥉 **เหรียญทองแดง**: 60.00 - 69.99 คะแนน
  - 🎖️ **เกียรติบัตรเข้าร่วม**: น้อยกว่า 60.00 คะแนน

### 4. ระบบผู้ดูแลระบบ (Admin Panel)
- **ภาพรวม & แก้ไขคะแนน**: ตรวจสอบคะแนนของกรรมการทุกคน และสามารถเข้าไปปรับแก้หรือเติมคะแนนแทนได้ทันที
- **จัดการห้องเรียน & ระดับชั้น**: เพิ่ม / ลบ / แก้ไข ห้องเรียนและระดับชั้นได้ตามต้องการ
- **จัดการกรรมการ**: แก้ไขชื่อกรรมการ มอบหมายระดับชั้น
- **จัดการเกณฑ์คะแนน**: ปรับเปลี่ยนชื่อเกณฑ์ คำอธิบาย และคะแนนเต็ม
- **ส่งออก Excel (.xlsx)**: ดาวน์โหลดไฟล์ Excel รวมทุกระดับชั้น แยก Sheet พร้อมสูตรและข้อเสนอแนะ
- **พิมพ์รายงานใบคะแนน (A4 / PDF)**: หน้าพิมพ์เอกสารทางการ พร้อมส่วนลงนามของคณะกรรมการ 3 ท่าน
